# VELVET — The Play Lounge

iPad の Safari で遊べる、日本語の仮想コイン制ゲームラウンジ。課金・換金・外部アカウントはありません。

## 起動

Node.js 20 以上で、リポジトリ内から実行します。

```sh
npm start
```

ポートは既定で `3000`。変更する場合は `PORT=8080 npm start`。アプリ実行に npm パッケージのインストールは不要です。サーバーは `0.0.0.0` で待ち受けます。iPad からは、到達可能なホストの URL またはデプロイ先の HTTPS URL を Safari で開いてください。クラウドのローカルアドレスは iPad から直接開けません。

静的ファイル（`index.html`、`src/`、`assets/`）だけでもホスティングできます。アセットは相対パスのため、GitHub Pages の `/Gyambule/` のようなサブディレクトリ配信にも対応します。外部フォント・外部 API・画像配信サービスへの依存はありません。

## ゲーム

- **ラッキー・セブン**：3 リール、ワイルド、最大 2 リール HOLD、8 回ごとに配当 2 倍のフィーバー。HOLD 後も通常のベットを消費。
- **ロイヤル・ダービー**：6 頭の速さ・体力・走法、1,200m / 1,600m、晴れ / 雨、単勝・複勝。展開アニメーション付き。固定オッズは的中確率を示すものではありません。
- **ミッドナイト・ルーレット**：ヨーロピアンの 0〜36。赤黒・奇偶・数字の一点賭け。
- **クラブ・トゥエンティワン**：ヒット・スタンド・ダブル、A の自動調整、ナチュラル 21 は 3:2、ディーラーはソフトを含む 17 でスタンド。毎ハンド 52 枚をシャッフル。スプリット・保険なし。

5,000 コインからスタート。毎日 1,000 コインを受け取り可能。残高が 50 未満ならリスタート用補充を利用できます。配当はすべてベット元本込み。ベット範囲は 10〜10,000（10 刻み）。

残高、直近 30 件の履歴、4 種の実績、進行中のブラックジャックは `localStorage` に保存。抽選済みのアニメーション中に再読み込みしても、配当は一度だけ精算されます。保存はブラウザ・端末ごとで、同期されません。同時プレイは 1 タブで行ってください。端末時刻・ローカル保存を使う娯楽用アプリで、改変防止や実通貨の取引機能はありません。

## 検証

```sh
npm ci
npm test
npm run check
# 別ターミナルで npm start を実行してから:
npm run test:browser
```

`npm test` は配当・ワイルド・A の計算・デッキ・競馬順位のテスト。`test:browser` は Playwright / Chromium を使い、4 ゲームのプレイ、コイン収支、リロード、報酬、実績、320 / 390 / 768 / 1024px のレイアウトを検証します。既定の Chromium パスは `/usr/bin/chromium`、変更は `BROWSER_PATH=/path/to/chromium npm run test:browser`。テスト用パッケージ以外にランタイム依存はありません。

iPad 向けに縦横レイアウト、タッチ操作、safe area、低モーション設定に対応。ホーム画面への追加は Safari の共有メニューから可能です（オフライン動作の保証はありません）。

### このクラウド環境での確認

エンジンの 8 テスト、構文チェック、Chromium のブラウザテストを実施。ブラウザテストには途中精算の二重加算防止、ブラックジャックのダブル・バスト、8 回目のフィーバーも含みます。Safari / WebKit の実行用バイナリはネットワーク許可リストによって取得を拒否されたため、iPad Safari 実機での検証は未実施です。

## GitHub Pages で公開

GitHub の **Settings → Pages → Build and deployment** で、Source を **Deploy from a branch**、Branch を **main**、フォルダーを **/ (root)** にして Save。デプロイ成功後の標準 URL は `https://haruto-ailab.github.io/Gyambule/` です。実際の URL と公開状況は Pages 設定で確認してください。

`.nojekyll` によって、HTML・CSS・JavaScript をそのまま配信します。Node.js サーバーは Pages 上では実行せず、ブラウザ内で全ゲームが動きます。
